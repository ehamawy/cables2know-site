# Cables2Know - Final Project Site

## About

This is a website created for my CS176 web design class.

It is made in pure vanilla HTML and CSS, with no Javascript, frameworks, templates, or LLM generated code.

It is a website to teach readers about various kinds of cables and chargers, what they look like, and how to tell the difference between them.
