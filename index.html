USB-C

General purpose cable

See main section: USB

What is it?

USB type C is a generic power and data cable primarily used for mobile devices. It can transfer power for charging cell phones, data for moving files, audio for headphones, and much more. It is the main port on all new cell phones.

History

It was first proposed in 2014, but gained widespread adoption around 2019. It is meant to be the modern replacement for USB-B, Micro-USB, and Mini-USB. Apple replaced their iPhone lightning connector with it in late 2023.
